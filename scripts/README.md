# Scripts

Four source-checkout entry points are implemented. All insert `src/` on
`sys.path` and work without installing the package. `_shared.py` holds the common
CLI override and JSON-summary helpers.

## `check_environment.py`

Read-only environment/capability report. It does not write files, make network
calls, or call paid APIs.

```powershell
python scripts\check_environment.py
python scripts\check_environment.py --json
```

Reports Python/platform, installed packages, loaded settings, FFmpeg/FFprobe
versions and required encoders/filters, local TTS availability, selected provider,
and whether `GEMINI_API_KEY` is configured. It explicitly reports
`gemini_live_call_tested: false` and `gemini_duration_control: false`.

Exit code: `0` when FFmpeg and FFprobe are found, `1` otherwise. A missing TTS path
is reported as a warning; the default deterministic provider then cannot render.

## `run_lesson_pipeline.py`

Runs the full implemented lesson flow: `LessonPlan` + per-scene
`ScenePlanningResult`/`VisualPlanningResult` JSON -> deterministic packaging ->
runtime adaptation -> generate -> validate -> assemble.

```bash
python scripts/run_lesson_pipeline.py \
  --lesson-plan examples/demo_lesson/lesson_plan.json \
  --planning-dir examples/demo_lesson/planning \
  --job-id demo
python scripts/run_lesson_pipeline.py ... --plan-only
```

When `--planning-dir` is omitted, the script runs live Gemini planning through the
configured adapter and requires `GEMINI_API_KEY` plus `google-genai`. Use
`--save-planning-dir` to persist the validated artifacts for later offline runs.

`--plan-only` packages and adapts scenes without requiring FFmpeg or a video
provider. The committed demo planning artifacts are deterministic fixtures
generated by `examples/build_demo_lesson.py`.

## `llm_smoke_test.py`

Sends one minimal structured-output request to the configured Gemini model,
validates the JSON response, and prints a concise result. It does not plan a
lesson or generate video and may incur provider charges.

```bash
export GEMINI_API_KEY=...
python scripts/llm_smoke_test.py --json
python scripts/llm_smoke_test.py --show-request --json
python scripts/llm_smoke_test.py --model gemini-3.8-flash --plain-logs
```

`--show-request` prints safe effective-request diagnostics (model, parameter
names, schema size, prompt lengths) without prompts or credentials. HTTP 4xx
failures print the sanitized provider message, status/reason, and invalid field
when reported. Exit code `0` on a valid response, `1` on configuration, provider,
or format failure. This command is never part of the automated test suite.

## `run_pipeline.py`

Runs the implemented generate -> validate -> assemble pipeline over a canonical
runtime `SceneSet` JSON file.

```powershell
python scripts\run_pipeline.py --scene-set examples\scene_set.sample.json --job-id demo1
python scripts\run_pipeline.py --width 640 --height 360 --fps 12 --no-intro --no-outro --plain-logs
python scripts\run_pipeline.py --provider gemini_omni --job-id gemini-demo
```

Options include `--config-dir`, `--provider`, `--width`, `--height`, `--fps`,
`--no-intro`, `--no-outro`, `--plain-logs`, `--log-level`, and `--cancel-file`.

`--cancel-file` enables cooperative cancellation: creating the file requests a
stop between work units. The process prints a JSON summary and returns:

- `0`: completed;
- `1`: failed or input/configuration error;
- `2`: cancelled.

Side effects: writes scene/final artifacts and the artifact registry under the
configured storage root (`artifacts/` by default), and temporary work directories
under the configured temp root. The default provider is local and free. Selecting
`gemini_omni` makes paid API calls and requires `GEMINI_API_KEY`.
